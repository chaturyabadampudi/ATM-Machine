# ATM MACHINE SIMULATION
A menu-driven ATM simulation developed using C.
## Technologies used:
- C programming
- Code::Blocks
## Features:
- ATM menu
- Basic banking operations
## How to Run:
1. Download the source code.
2. Open it in Code::Blocks IDE.
3. Compile and run.
## PIN information
- Demo pin: 1234
- The program displays an invalid PIN message if an incorrect PIN is entered.
- The PIN is hardcoded for demonstration purposes.
